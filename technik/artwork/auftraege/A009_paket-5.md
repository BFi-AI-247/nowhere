## New standing rule from the Betreiber (06.11.2026, 06:26)

His wording: „Sag ihm, wenn einmal abgelehnt ist, soll er es nicht weiter versuchen, sondern auf den nächsten Run
warten."

One refusal is final for that run. If the generator refuses a picture, returns an empty result or errors for any
reason – quota, a declined prompt, a failure without text – do not try that picture again in the same run. Do not
reword it, do not try it with a different tool. Deliver it with status blocked and the error text as you received
it, and let the next run take it. This replaces the two attempts of M007 and the four of M003: from now on it is
one attempt per picture, per run.

This applies to a refusal. A picture that arrives but comes out wrong (visible hands, lettering, the wrong style)
is not a refusal: deliver it once with status unsicher and say what you see, as you have been doing.

The Betreiber also says the next run is in a few hours, so there is no hurry on any of this.
